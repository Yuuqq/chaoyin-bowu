# 潮音博物 · 汕头濠江方言风物录

汕头大学“潮音博物”课题组整理的潮汕方言风物录。首期以汕头市濠江区为样板，收入农渔饮食、非遗百工、侨乡俗谚三类风物共18条，每条给出潮汕正字、1960年《潮州话拼音方案》读音、国际音标、声调走势、音韵与做法说明及所在地点。

## 文件

- `seed_data.js`、`kg_data.js`：词条与图谱数据，由项目脚本生成，请勿手改
- `app.js`：词条排版、声调图与示意音的共用脚本
- `theme.css`：全站样式

声调示意音按五度走势合成，并非真人录音。
