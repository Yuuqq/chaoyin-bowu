# 潮音博物（Chaoyin-Bowu）· 粤东县域潮汕方言多模态博物图谱原型系统 V0.1

汕头大学跨学科研究团队研发的粤东县域潮汕方言名物数字化建档、双腔声学比对与受控图谱检索导览示范平台（首期试点：**汕头市濠江区“一区四街五点”**）。
